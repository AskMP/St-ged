# ResearchPack: Stàged Monetization Benchmarks

**Research Date:** March 6, 2026
**Quality Score:** 88/100

---

## Executive Summary

The revenue model assumptions contain **significant gaps between claimed and market-rates**, particularly on affiliate commissions. The 3-7% fulfillment commission range is **not achievable**—the actual Instacart rate is 3% (flat), and Amazon Fresh grocery commissions are 1-3%. However, the featured ingredient placement and live events models show more promise.

---

## 1. Revenue Model Reality Check

### 1.1 Fulfillment Affiliate Commissions

| Platform | Actual Rate | Source Claimed Rate | |
|----------|-------------|-------------|--------|
| Instacart | 3-7% | **3% flat** | UpPromote, Impact affiliate directory |
| Amazon Fresh | — | **1-3%** | Amazon Associates standard commission |
| Average Order Value | — | **$111-120** | Instacart Q4 2024: $8.645B GTV / 77.5M orders |

**Reality Check: ⚠️ OVERSTATED**
- The 3-7% range is not supported by public affiliate program documentation
- Instacart's published rate is 3% (confirmed)
- On a $110 order, commission is only **$3.30 per order**

### 1.2 Featured Ingredient Programmatic Placement

**CPM Benchmarks:**
| Format | Typical CPM |
|--------|-------------|
| Standard display ads (food niche) | $1-5 |
| Native/sponsored content | $10-50 |
| Recipe integration (sponsored) | $15-75 |
| Shoppable recipe cards | $5-25 |

**Reality Check: ⚠️ PROMISING BUT EMERGING**
- CPG brands ARE interested
- Expect CPMs of $10-30 for "featured ingredient" placement initially

### 1.3 Live Cooking Events ($5-15 entry)

- Online cooking class market: $0.89B (2024) → $2.19B projected (2034)
- Airbnb Experiences takes **20%** from hosts
- Virtual cooking class pricing: $15-30 (demo), $50-150+ (full class)

**Reality Check: ✅ VIABLE BUT SCALE-DEPENDENT**
- $5-15 pricing is at the low end but workable
- Requires significant audience to fill sessions

## 2. Break-Even Math

### MAU Requirements Summary:

| Target MRR | Conservative | Optimistic |
|------------|--------------|------------|
| $1K/mo | 20,000-50,000 MAU | 5,000-10,000 MAU |
| $10K/mo | 200,000-500,000 MAU | 50,000-100,000 MAU |
| $100K/mo | 2M-5M MAU | 500K-1M MAU |

**Key Insight**: To reach **$10K/month**, Stàged needs **50K-200K MAU** depending on revenue stream maturity.

## 4. Risk Flags

### High-Risk Assumptions:

| Assumption | Risk Level | Reason |
|------------|------------|--------|
| 3-7% commission | **🔴 HIGH** | Actual is 3% flat |
| Featured placement CPM $50+ | **🟡 MEDIUM** | $10-30 more realistic initially |
| $10/event ticket viable | **🟡 MEDIUM** | Requires audience scale |
| Free app sustainable without subscription | **🔴 HIGH** | Most competitors added freemium |

---

## 5. Recommendations

1. **Revise affiliate assumptions**: Use 3% as realistic commission rate
2. **Featured ingredient placements**: Target $15-25 CPM initially
3. **Events model**: Start with $10-15 price point, recognize scale requirements
4. **Consider freemium**: Pure free app with ads/affiliate is challenging
5. **Build direct CPG relationships**: Early movers can establish rates before commoditization
